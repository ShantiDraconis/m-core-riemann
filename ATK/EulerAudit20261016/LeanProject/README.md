# ATK RH — Lean 4 / Mathlib

Target toolchain: Lean 4.35.0. Mathlib release tag `v4.35.0` is requested, subject to its availability upstream.

Run on Linux/macOS with Internet:

```bash
bash install_and_check.sh
```

If Mathlib's `v4.35.0` tag is unavailable, use the Mathlib `master` toolchain and matching revision instead; do not mix versions. This source is NOT yet kernel-verified.

The lemmas are algebraic and conditional; this project does not prove the Riemann hypothesis.
