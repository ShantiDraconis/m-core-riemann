# M-Core Riemann research architecture

Scientific status: research scaffold, not a proof of RH.

Pipeline: Official statement → Specification → Foundations ζ → nontrivial-zero Objects → Signature → Boundary atlas → ProofDAG → AttackDAG → Bridges → Adapters → Frontier → Endpoint → Axiom/dependency audit → independent reproduction.

Signature: I_RH(ρ)=|Re(ρ)-1/2| for nontrivial ζ-zero ρ. Global candidate Ω_RH=sup I_RH where the extended-real supremum is rigorously defined. Target: every nontrivial zero has I_RH=0.

Boundary protocol: REGULAR → PRE_BOUNDARY → BOUNDARY → CROSSING → POST_BOUNDARY. Explicitly test critical-line approach, zero/pole contamination, left/right and multipath limits, removable/nonremovable singularities, oscillation, compactified infinity and whether a post-boundary extension exists. 0/0 is recorded only when a naturally derived quotient actually has numerator and denominator tending to zero.

Attack loop: continuation/functional equation → zero classification → critical strip/symmetry → zero-control estimates → signature → check whether estimates assume RH-equivalent zero information.

Cross-problem relations require certified adapters; numerical zero verification cannot prove the universal statement.
